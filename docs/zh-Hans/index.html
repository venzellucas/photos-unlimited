安装前
请了解几点。

这是一款独立应用的早期版本。以下是你可以预期的情况。

存储空间真的无限吗？+

应用使用未公开的移动协议，并通过 Pixel 上传配置文件请求原始画质的处理方式。是否接受上传以及配额如何计算均由 Google 控制，因此上传被接受并不保证免占存储空间。在依赖本应用之前，请验证新的示例上传和实际存储用量。已存在的匹配项保留其原有的计费方式。

能释放旧上传内容占用的存储空间吗？+

可以，使用“释放存储空间”功能。每个项目的原件都会先对照 Google 自己的校验和逐字节验证，并保存在你的手机上，然后才会删除该项目并重新上传，因此日期和位置等嵌入的元数据保持完整。请先关闭 Google 相册备份。在 Google 相册内创建的相册、人脸分组和所做的编辑不会保留。建议先从少量项目开始。

我的账号和文件会怎样？+

应用直接把文件发送到 Google，并将你的登录凭据加密保存在 Android 应用的私有存储空间中，且不纳入 Android 备份。头像和可选的存储空间清单会缓存在本地。应用在打开期间每天会向 GitHub 查询一次是否有新版本；你可以关闭此功能。本项目没有自有的账号服务器，也没有分析 SDK。请阅读隐私说明。

它有多可靠？+

核心上传功能已在真实设备上使用过。每个版本都会通过自动化测试和签名升级检查。1.0.0 版本还经过了独立的安全审查。实时存储计费情况尚未完全验证。Google 可能更改这些未公开的方法。传输中断后会从头重新传输该文件。支持动态照片；成对的 iPhone Live Photos 不会被替换。
