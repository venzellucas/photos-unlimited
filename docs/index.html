Get started

Three steps to your first backup.

  1. 1

    Connect your account

    Use Google’s setup flow in the app. A browser setup-token fallback is available if embedded sign-in doesn’t work.

  2. 2

    Choose your folders

    Allow full photo, video, and media-location access. Select the folders you want to back up, including their existing files.

  3. 3

    Start your backup

    Turn off automatic backup in the official Google Photos app, then tap Back up now in Photos Unlimited.

Android manages background timing. Network, charging, battery, and idle settings can delay automatic uploads.

Good to know

A few things
before you install.

This is an early release of an independent app. Here’s what to expect.

Is storage really unlimited?+

The app uses an undocumented mobile protocol and requests original-quality treatment with a Pixel upload profile. Google controls acceptance and quota accounting, so an accepted upload does not guarantee storage exemption. Verify fresh sample uploads and actual storage usage before relying on it. Existing matches retain their accounting.

Can it free storage used by older uploads?+

Yes, with Free up storage. Each item's original is verified byte-for-byte against Google's own checksum and kept on your phone before the item is deleted and uploaded again, so embedded metadata such as dates and location stays intact. Turn off Google Photos backup first. Albums, faces and edits made inside Google Photos are not kept. Start with a few items.

What happens to my account and files?+

The app sends files directly to Google and keeps your sign-in encrypted in private Android app storage, excluded from Android backup. Profile photos and the optional storage inventory are cached locally. Once a day while the app is open, it asks GitHub whether a newer version exists; you can turn this off. There is no project-owned account server or analytics SDK. Read the privacy notes.

How reliable is it?+

Core uploads have been used on a real device. Each release passes the automated tests and a signed upgrade check. Version 1.0.0 also had an independent security review. Live storage accounting is not fully validated. Google can change the undocumented methods. Interrupted transfers restart the file. Motion Photos are supported; paired iPhone Live Photos are not replaced.
