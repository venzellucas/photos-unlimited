# Security policy

## Supported version

Only the latest release gets security fixes. Update to it before reporting.

## Reporting a problem

Report security problems privately through GitHub:
<https://github.com/venzellucas/photos-unlimited/security/advisories/new>

Please don't open a public issue for a security problem.

## What never to include

Don't include tokens, cookies, email addresses or private photos in a report, a screenshot or a
log. Describe the problem and how to reproduce it; that is enough to start.
